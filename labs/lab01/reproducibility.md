# Инструкция по повторению диагностики

## Предварительные требования
- Установленная ОС Linux (~~желательно~~ обязательно Arch Linux)
- Доступ к терминалу
- Уметь пользоваться терминалом
- Уметь читать доки и ArchWiki

## Пошаговая инструкция

### Шаг 1: Поставить Arch или Debian

Проще всего ставить Debian, но его автоустановка сильно ограничевает выбор в компанентах и файловых системах.

Арч более сложный, но есть лёгкий вариант в лице:
```bash
archinstall
```
Неофициальный установщик, который имеет куча опций и большой выбор компанентов: от оболочки до файловых систем и типов базовых функций(Я до сих пор не пойму почему люди всё ещё не ставят zram за место swap, это значительно лучше и безопаснее для ssd!)

### Шаг 2: Установка FastFetch
```bash
sudo pacman -S fastfetch        # Для Arch Linux
# или
sudo apt install fastfetch      # Для Ubuntu/Debian
