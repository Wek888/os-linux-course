# Классификация ОС Arch Linux

| Характеристика | Значение | Почему? |
|----------------|----------|---------| 
| **Назначение** | Desktop | Модель разработки Rolling Release, что делает её менее пригодной для серверов |
| **Число задачь** | Многозадачная | Ну блин, это не калькулятор |
| **Работа с пользователями** | Многопользовательская | Унаследовав от Unix свою природу |
| **Интерфейс** | Комбинированный | Есть Xfce4, но добрая часть задач, выполняется в терминале |
| **Сфера применения** | Общего назначения | Может запускать от игр до сложного графического софта, да и прост ютубчик можно посмотреть |
| **Поддержка сети** | Локальная/сетевая работа | Ну... имеет браузер, и куча НЕ предустановленных сетевых компонентов, типа: Firewall |
