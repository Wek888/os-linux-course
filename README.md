# Предмет Операционные системы и среды
Курс по изучению истории и работы разных операционных систем.

Ключевые моменты курса на момент

* Установка Ubuntu
* Изучение файловых систем: Ext4, Fat32, NTFS
* Изучение истории становление ОС

## Цели:
* Улучшить знания в ОС Linux
* Укрепить знание в Gnu/Linux и немного в FreeBSD...
* Хорошо провести время

## Структура
* Assets - папка ассетов для md файлов
* labs - лабораторные работы
* reports - отчёты о пк, типе ос и источники ИИ
* scripts - Скрипты для переноса конфигов и настроек системы
